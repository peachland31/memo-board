# 메모 보드

혼자 쓰는 포스트잇 캔버스 메모장. 빌드 없이 HTML/CSS/JS 세 파일로 돌아가고 GitHub Pages로 배포합니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 새 메모 | 빈 곳 더블클릭 · `+ 메모` 버튼 · `N` 키 |
| 메모 이동 | 메모 윗부분(날짜 줄)을 드래그 |
| 크기 조절 | 메모 오른쪽 아래 모서리 드래그 |
| 색 바꾸기 / 삭제 | 메모에 마우스를 올리면 나오는 ● / × |
| 보드 이동 | 빈 곳 드래그 · 트랙패드 스크롤 |
| 확대/축소 | 트랙패드 핀치 · ⌘/Ctrl + 스크롤 · 상단 버튼 |
| 검색 | `/` 키, Enter 누르면 첫 결과로 이동 |

비워 둔 메모는 포커스를 벗어나면 자동으로 사라지고, 삭제는 6초 안에 되돌릴 수 있어요.

## 백업 구조

1. **즉시 저장**: 입력할 때마다 브라우저 `localStorage`에 저장
2. **복원 지점**: 변경이 있으면 3분마다 IndexedDB에 스냅샷 (최근 100개). 백업 창에서 원하는 시점으로 복원
3. **GitHub Gist 동기화** (선택): 비공개 Gist `memo-board.json`에 변경 2초 뒤 자동 업로드, 창을 다시 볼 때·2분마다 내려받아 메모별로 최신 버전을 병합
4. **JSON 내보내기/가져오기**: 수동 백업 파일

### Gist 동기화 켜기

1. [gist 권한 토큰 만들기](https://github.com/settings/tokens/new?scopes=gist&description=memo-board) (classic token, `gist` 권한만)
2. 메모 보드 → `백업` → 토큰 붙여넣기 → `연결`
3. 다른 기기에서도 같은 토큰으로 연결하면 기존 Gist를 찾아 불러옵니다

토큰은 이 브라우저의 localStorage에만 저장됩니다. `gist` 권한만 주세요.
